## Create a property

Open **Properties → All Properties**, then select **New Property**. The form asks for:

1. A property name.
2. A property type.
3. Address, province, city or kabupaten, and postal code.
4. An optional phone number.

After saving, the property becomes the home for its units, leases, tenants, documents, and maintenance history.

## Find a property

The property list supports search and column filters. Useful columns include:

- Name and property type.
- City.
- Total units.
- Occupied units.
- Tenants.
- Active or archived status.

Open a property to move from the list into its workspace. The workspace keeps the property overview, units, leases, documents, and related history together.

## Add units

From a property workspace, add each rental unit and set its type, rate, capacity, and availability. Use a consistent naming convention so tenants and staff can identify units quickly.

The unit workspace can show:

- Current lease and tenant.
- Lease history.
- Maintenance history.
- Unit documents.

## Unit availability

OpenKOS uses unit status to protect operational workflows:

- **Available** — can receive a new lease or tenant assignment.
- **Occupied** — has an active lease.
- **Maintenance** — blocked from new leases, assignments, and moves.
- **Unavailable** — blocked for another reason.

When a maintenance ticket blocks an occupied unit, the property team can keep the tenant in place or transfer the lease to another available unit. The lease continues; the unit change is recorded in history.

<Tip>
  Set up property types before creating a large portfolio. It keeps property filtering and reporting consistent.
</Tip>
