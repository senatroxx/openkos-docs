Open **Maintenance** to track issues from the first report through resolution. The list can be filtered by title, property, priority, status, and created date.

## Create a ticket

1. Select **New Ticket**.
2. Choose the property and unit.
3. Describe the issue clearly.
4. Set the priority.
5. Optionally block the unit for maintenance.
6. Save the ticket.

Use a title that describes the action needed, not only the symptom. Include where the problem is and what the tenant already tried.

## Ticket status

The normal workflow is:

**Reported → In progress → Resolved**

Keep the ticket open while work is still being coordinated. Use the ticket detail page for the description, assignment, status, and history.

## Block a unit

Blocking a unit prevents new leases, tenant assignments, and moves into that unit.

If the unit is empty, it can be marked for maintenance immediately. If it is occupied, OpenKOS asks the property team to choose between:

- Keeping the tenant in the current unit while maintenance is handled.
- Moving the active lease to another available unit before blocking the original unit.

The second option changes the physical unit but preserves the lease agreement and records the transfer.

## Restore availability

When resolving or cancelling a ticket, select the restore option when the unit is ready. The unit stays blocked if another open ticket still requires it to remain unavailable.

<Tip>
  Resolve the ticket only after the unit is safe to use. The restore check is a deliberate operational decision, not an automatic side effect of changing the ticket status.
</Tip>
