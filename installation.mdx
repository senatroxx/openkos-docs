Choose the installation path that matches your goal:

- **Clone the repository** for local development, customization, and contribution.
- **Use a published release image** for a repeatable deployment managed with Docker Compose.

## Prerequisites

For a source checkout, install:

- PHP 8.4 or newer with the required extensions
- Composer
- Node.js 22 or newer and npm
- PostgreSQL 16 or newer

SQLite and MySQL are not tested for the application.

## Install from the repository

Clone the repository and install dependencies:

```bash
git clone https://github.com/senatroxx/openkos.git
cd openkos
composer install
npm install
```

Run the interactive installer:

```bash
php artisan app:install
```

The installer asks for database, site, timezone, and owner details, generates the application key, runs migrations, and creates the first owner account.

Start the local services:

```bash
composer run dev
```

This runs the Laravel server on port 8080, the database-backed queue worker, Pail logs, and Vite with hot module replacement. Open [http://localhost:8080](http://localhost:8080) after the services are ready.

For individual processes, see [Local development setup](/developers/setup).

## Use a published release image

OpenKOS publishes versioned images through [GitHub Container Registry](https://github.com/senatroxx/openkos/pkgs/container/openkos). The current published release is `0.1.0-alpha.5`; the repository also publishes a moving `nightly` tag. There is no `latest` tag.

Pin an explicit release for repeatable deployments:

```bash
OPENKOS_IMAGE=ghcr.io/senatroxx/openkos:0.1.0-alpha.5
docker compose -f compose.production.yaml pull
docker compose -f compose.production.yaml run --rm web php artisan migrate --force
docker compose -f compose.production.yaml up -d
```

Configure the production environment before starting the release image. See [Production deployment](/deployment) for PostgreSQL, proxy, TLS, queue, scheduler, and upload-volume requirements.

<Warning>
  Use the `nightly` image only for testing. It is a moving build, not a production release.
</Warning>
