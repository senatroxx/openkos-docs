## Technology at a glance

| Area | Technology |
| --- | --- |
| Backend | PHP 8.4 and Laravel 13 |
| Frontend | React 19, Inertia 3, and TypeScript |
| UI | shadcn/ui and Tailwind CSS 4 |
| Authentication | Laravel Fortify |
| Authorization | Spatie Permission |
| Typed routes | Laravel Wayfinder |
| Database | PostgreSQL |
| Queue | Laravel database queue |
| Tests | Pest 4 |

## Repository map

- `app/` contains application code: actions, business rules, models, controllers, policies, jobs, notifications, and services.
- `src/` contains application-owned plugins.
- `openkos-platform/` is the reusable platform package with registries, contracts, events, and the plugin lifecycle.
- `resources/js/` contains the React and Inertia client.
- `routes/` contains web, settings, API, and console route definitions.
- `tests/` contains Pest feature and unit tests.

## Contribution rule of thumb

Before adding a new abstraction, look for an existing action, business class, registry, component, or route pattern that already fits. Keep controllers thin, keep domain rules testable, and record lasting architectural trade-offs as ADRs.

<Note>
  OpenKOS is v0.1 Alpha. Expect breaking changes while the platform and plugin APIs continue to stabilize.
